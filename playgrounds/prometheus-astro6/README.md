# Prometheus Playground (Astro 6)

Pinned e2e playground for `astro-prometheus-node-integration` on **Astro 6** with **`@astrojs/node` v10**.

See [`../README.md`](../README.md) for the playground versioning policy.

## Stack

| Package | Version |
|---|---|
| `astro` | 6.x |
| `@astrojs/node` | 10.x |
| `astro-prometheus-node-integration` | workspace |

## Commands

From the repo root:

```bash
pnpm prometheus-astro6:playground:dev
pnpm prometheus-astro6:playground:build
pnpm test:e2e:prometheus-astro6
```
