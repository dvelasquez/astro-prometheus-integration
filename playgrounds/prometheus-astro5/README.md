# Prometheus Playground (Astro 5)

Pinned e2e playground for `astro-prometheus-node-integration` on **Astro 5** with **`@astrojs/node` v9**.

See [`../README.md`](../README.md) for the playground versioning policy.

## Stack

| Package | Version |
|---|---|
| `astro` | 5.x |
| `@astrojs/node` | 9.x |
| `astro-prometheus-node-integration` | workspace |

## Commands

From the repo root:

```bash
pnpm prometheus-astro5:playground:dev
pnpm prometheus-astro5:playground:build
pnpm test:e2e:prometheus-astro5
```
